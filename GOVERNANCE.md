# Governance Basics

This document defines the maintainer contact path and lightweight governance
expectations for Jigsaurium.

## Maintainers

- Primary maintainer team: repository owners/maintainers in
  `turbotas/Jigsaurium`.

## Maintainer Contact Path

Use these channels:

1. **General maintainer contact (default)**
   - Open a GitHub issue in this repository and include `[Maintainer Contact]`
     in the title.
2. **Code of Conduct reports**
   - Use the path above and include `[CoC Report]` in the title.
   - Provide only details needed for triage; maintainers will continue sensitive
     handling in a reduced-visibility path as available.
3. **Security reports**
   - Follow `SECURITY.md` (private vulnerability reporting path once public).

When the repository is public, maintainers may provide additional private
contact channels in this file.

## Governance Expectations

- Maintainers make final merge/release decisions.
- Changes should align with repository specs under `Documentation/`.
- Significant disputes or moderation actions are handled by maintainers under
  `CODE_OF_CONDUCT.md`.
- Major policy/process changes should be documented in
  `Documentation/decisions.md`.
